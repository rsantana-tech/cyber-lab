# Cyber Lab Roadmap

This roadmap outlines the technical areas and practical projects planned for this laboratory.

The objective is to progressively develop real technical skills through structured learning and experimentation.

---

## Phase 0 — Environment Setup

Initial preparation of the development environment.

Focus:

- Git and GitHub workflow
- Project structure
- Development tools configuration
- Logging and documentation structure

---

## Phase 1 — Python Foundations

Learning Python fundamentals through practical exercises.

Topics:

- variables
- conditionals
- loops
- functions
- file manipulation

Projects planned:

- password generator
- log parser
- small automation scripts

---

## Phase 2 — Automation

Using Python to automate repetitive tasks.

Topics:

- file automation
- system interaction
- scripting tools
- command-line utilities

Projects planned:

- directory organizer
- automated file backup
- system monitoring script

---

## Phase 3 — Software Testing (QA)

Introduction to testing practices.

Topics:

- testing concepts
- test cases
- API testing
- automation frameworks

Projects planned:

- API test scripts
- automated test scenarios

---

## Phase 4 — Databases

Working with structured data.

Topics:

- SQL basics
- PostgreSQL
- data queries
- database automation

Projects planned:

- database interaction scripts
- query automation

---

## Phase 5 — Networking and Security

Understanding how systems communicate and how they can be secured.

Topics:

- networking basics
- ports and protocols
- security fundamentals
- simple network tools

Projects planned:

- port scanner
- network monitoring script
