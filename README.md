# Cyber Lab

Personal technology laboratory focused on practical learning, experimentation, and development of real technical skills.

This repository documents my continuous learning journey in areas such as programming, automation, software testing, databases, networking, and cybersecurity.

The goal of this lab is not only to study theory, but to build practical experience through experiments, scripts, exercises, and small projects.

---

## Objectives

- Develop solid programming skills
- Build practical experience with automation
- Practice software testing concepts (QA)
- Learn database fundamentals and data manipulation
- Understand networking and security concepts
- Maintain a structured and disciplined technical learning process

This lab serves as a central workspace where ideas are tested, tools are explored, and technical knowledge is progressively built.

---

## Structure

The repository is organized to reflect a practical learning environment.
cyber-lab
│
├── logs → progress logs and study records
├── notes → technical notes and study summaries
├── exercises → small coding exercises and experiments
├── projects → practical projects and prototypes
└── tools → scripts and utilities created during the learning process


Each section represents a different stage of the learning process, from theoretical understanding to practical implementation.

---

## Learning Approach

The approach used in this lab follows a simple principle:

**Learn → Practice → Build → Document**

Instead of only consuming theoretical content, the focus is on applying knowledge to small practical problems and gradually building more complex solutions.

This method helps develop real technical ability rather than only conceptual familiarity.
